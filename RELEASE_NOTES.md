# Taskbar Folders — v1.4.0

**First stable release** · November 2026

---

### English

First stable release of **Taskbar Folders**.

#### Highlights
- **Scan this PC** — scans Start-menu apps, auto-categorises them and can create one folder per category
- Custom folder colours and icons
- Flexible 1–4 column layouts
- Multiple themes + opening animations
- Easy pinning with automatic detection
- Single manager instance + config backup
- Almost zero idle RAM usage

#### Requirements
- Windows 11
- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (x64)

#### How to use
1. Place `TaskbarFolders.exe` in a permanent folder.
2. Create folders or use **Scan PC…**.
3. Pin a folder with the Pin button or by dragging.
4. Click the pinned icon to open the menu.
